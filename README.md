# 🍺 Homebrew Tap for IEEE Computer Society (`ieeecsopen/tap`)

Official Homebrew tap for tools and packages maintained by the **IEEE Computer Society of SLIIT**.

---

## 📦 Available Formulae

| Formula | Description | Install Command |
| :--- | :--- | :--- |
| **`mcp-cs`** | Universal Developer Operations, Diagnostics & AlgoJudge Competitive Execution MCP Server | `brew install ieeecsopen/tap/mcp-cs` |

---

## 🚀 Installation

Add this tap to your Homebrew installation:
```bash
brew tap ieeecsopen/tap
```

Then install any tool:
```bash
brew install mcp-cs
```

Or install directly in one command:
```bash
brew install ieeecsopen/tap/mcp-cs
```
